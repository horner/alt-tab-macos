# AltTabProjects 1.0.7 — Quieter window notifications

Opening or restoring a window on its Project's current Desktop no longer shows an assignment toast.

When a restored window belongs to a Project on another Desktop, the notification offers “Move to Project’s Desktop”. Moving is optional and keeps you on your current Desktop. The action rechecks the window and its destination before moving it; resolved or changed conflicts are discarded. Windows matching several Projects still offer a membership choice.

Update through Settings → General → Check for updates now…, or run `brew update` followed by `brew upgrade --cask --greedy horner/projects/alttab-projects`. Version 1.0.5 and earlier require a manual download or Homebrew upgrade before built-in updates become available.

Existing Projects, preferences, permissions and the app's signing identity are retained. Intel and older-macOS runtime testing remain outstanding.
