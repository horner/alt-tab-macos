# AltTabProjects 1.0.6 — Automatic updates

AltTabProjects can now check for friends-beta updates in the background and download, install and relaunch through its built-in updater. New installations check daily and ask before installing. Settings → General lets you check immediately or choose manual checks, automatic checks or automatic installation; existing saved choices are retained.

Version 1.0.5 and earlier need one manual download or Homebrew upgrade to this version before built-in updates become available. Homebrew users can run `brew update` followed by `brew upgrade --cask --greedy horner/projects/alttab-projects` for that first upgrade. Later updates can use the built-in updater.

Existing manual update policies remain manual. Choose “Check for updates periodically” in Settings → General to enable daily checks, or use “Check for updates now…” at any time.

Desktop navigation ignores stale windows whose application no longer has a valid process, so they cannot block switching to a populated Desktop.

The local signed upgrade test retained saved Projects, checked settings and existing macOS permissions. The app keeps its established signing and bundle identity. Activated-license, Intel and older-macOS runtime testing remain outstanding.
