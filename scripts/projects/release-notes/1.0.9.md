# AltTabProjects 1.0.9 — Desktop destinations stay available

Desktop labels remain available in Command-Tab after switching to another Desktop, including when the shortcut shows windows from visible Desktops only. Your monitor filter and ordinary window exclusions still apply.

Labels on other Desktops are discovered without visiting each Desktop first. Creating a Desktop no longer leaves existing Desktop destinations missing from the switcher.

Update through Settings → General → Check for updates now…, or run `brew update` followed by `brew upgrade --cask --greedy horner/projects/alttab-projects`. Version 1.0.5 and earlier require a manual download or Homebrew upgrade before built-in updates become available.

Existing Projects, preferences, permissions and the app's signing identity are retained. Intel and older-macOS runtime testing remain outstanding.
