# AltTabProjects 0.1.4 — Project folders

Choose a primary folder for each Project, then open iTerm2 or VS Code directly from its desktop label. Click **Folder…** to choose or replace the folder. A normal tool click focuses the most recently used eligible window already in that Project; right-click **New Window** to open another one in the saved folder. Folder choices survive relaunches and remain editable in the Project's YAML file.

Desktop labels and Project numbers now follow saved ownership consistently. Each Desktop has one Project owner, conflicting assignments remain available without being attached to an unrelated Desktop, and project saves can finish when quitting from a label menu.

AltTabProjects enables Projects and all features by default, with Command-Tab for window switching and Option-Tab for Projects. Saved preferences still take priority. Purchase prompts are hidden, and existing stored license data is preserved.

## Compatibility and limitations

- **macOS 12 Monterey or later is required.** This release updates deprecated APIs for the current build tools. The established Developer ID, Team ID, and bundle ID are unchanged.
- iTerm2 may ask for macOS Automation permission. VS Code uses its bundled launcher, so a `code` command on PATH is unnecessary.
- Folder buttons reuse existing Project windows without changing their current directory or workspace. Choose **New Window** to open the saved folder again.
- Creating another VS Code window manually at the same time as a folder launch can make the new window's Project assignment ambiguous.
- On macOS 27, App Exposé's trackpad gesture can target the previously active application while AltTabProjects is active. Control–Down targets AltTabProjects correctly. This OS behavior was reproduced independently and reported to Apple; this release does not fix it.
- Intel and older supported macOS versions still need hands-on runtime testing. Universal packaging does not establish that coverage.

## Install or update

For an existing Homebrew installation:

```sh
brew update
brew upgrade --cask horner/projects/alttab-projects
```

For a first installation:

```sh
if brew command trust >/dev/null 2>&1; then brew trust --cask horner/projects/alttab-projects; fi
brew tap horner/projects https://github.com/horner/alt-tab-macos.git
brew install --cask horner/projects/alttab-projects
```

Or download `AltTabProjects.zip`, move the app to Applications, and grant Accessibility and Screen Recording access when requested. Quit other AltTab variants before opening it.
