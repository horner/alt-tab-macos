# AltTabProjects 0.1.5 — Preferences persistence

Saved settings now survive repeated app launches without running old upstream migrations again. AltTabProjects tracks the preferences schema independently of its product version, preserving language, window visibility, gestures and grouping choices saved by earlier 0.1.x releases. Genuine upgrades from older upstream preferences still migrate once, and an older app does not lower a newer schema marker.

This update includes the Project folder launchers and desktop ownership improvements introduced in [0.1.4](https://github.com/horner/alt-tab-macos/releases/tag/projects-v0.1.4).

## Compatibility and validation

macOS 12 Monterey or later is required. The Developer ID, Team ID and bundle ID remain unchanged. All 1,744 native tests and 38 deployment-tool tests passed, including startup and relaunch regression tests. Publication additionally requires recorded runtime checks against the exact signed package installed and running locally. Intel and older supported macOS versions still need separate hands-on coverage.

The existing folder-launch limitations and macOS 27 App Exposé gesture issue described in the 0.1.4 notes still apply.

## Install or update

For an existing Homebrew installation:

```sh
brew update
brew upgrade --cask horner/projects/alttab-projects
```

Or quit AltTabProjects, extract `AltTabProjects.zip`, replace the existing app in Applications, and relaunch it. Keep your existing preferences and Projects data.
