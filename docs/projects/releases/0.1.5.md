# AltTabProjects 0.1.5 — Project visibility and saved settings

Selecting a Project now shows all of its windows across Desktops and displays, plus windows on the current Desktop even when they belong to another Project. Showing those windows does not change their membership. The conflicting “Show from active Project” setting has been removed. Hidden/minimized and other non-location filters still apply.

Project switching no longer automatically minimizes other Projects. The old “Minimize inactive projects” option has been removed; the app recovers windows it previously minimized without restoring windows you minimized yourself. Normal window minimize actions and Project label controls remain available.

Saved settings survive repeated app launches without running old upstream migrations again. AltTabProjects tracks the preferences schema independently of its product version, preserving language, window visibility, gestures and grouping choices saved by earlier 0.1.x releases. Genuine upgrades from older upstream preferences still migrate once, and an older app does not lower a newer schema marker.

Importing an older Project with the same name as a different saved Project now preserves both. The imported Project receives a distinct name, keeping its identity, window history and patterns while preserving existing Project files and notes. Interrupted imports resume without creating duplicates.

This update includes the Project folder launchers and desktop ownership improvements introduced in [0.1.4](https://github.com/horner/alt-tab-macos/releases/tag/projects-v0.1.4).

## Compatibility and validation

macOS 12 Monterey or later is required. The Developer ID, Team ID and bundle ID remain unchanged. The release process runs the native and deployment-tool test suites, including Project visibility, import recovery, and startup/relaunch regressions. Publication additionally requires recorded runtime checks against the exact signed package installed and running locally. Intel and older supported macOS versions still need separate hands-on coverage.

The existing folder-launch limitations and macOS 27 App Exposé gesture issue described in the 0.1.4 notes still apply.

## Install or update

For an existing Homebrew installation:

```sh
brew update
brew upgrade --cask horner/projects/alttab-projects
```

Or quit AltTabProjects, extract `AltTabProjects.zip`, replace the existing app in Applications, and relaunch it. Keep your existing preferences and Projects data.
